**Go BARRY** = Real-time traffic intelligence platform for Go North East bus operations
- **Purpose**: Help bus supervisors manage traffic disruptions affecting 231 bus routes
- **Coverage**: Newcastle, Gateshead, Sunderland, Durham, North Tyneside, Northumberland

```javascript
const response = await axios.get(`${supabaseUrl}/rest/v1/table`, {
  headers: {
    'apikey': supabaseKey,
    'Authorization': `Bearer ${supabaseKey}`
  }
});

// Lazy-loaded modules (prevents import-time failures)
const lazyImportCache = new Map();
async function lazyImport(modulePath) {
  if (lazyImportCache.has(modulePath)) {
    return lazyImportCache.get(modulePath);
  }
  const module = await import(modulePath);
  lazyImportCache.set(modulePath, module);
  return module;
}
```
