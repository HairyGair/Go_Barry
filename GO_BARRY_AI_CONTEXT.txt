```javascript
// Lazy-loaded modules (prevents import-time failures)
const lazyImportCache = new Map();
async function lazyImport(modulePath) {
  if (lazyImportCache.has(modulePath)) {
    return lazyImportCache.get(modulePath);
  }
  const module = await import(modulePath);
  lazyImportCache.set(modulePath, module);
  return module;
}
```

## 🔧 TROUBLESHOOTING COMMON ISSUES

### **503 Service Unavailable Errors**
- **Cause**: Backend memory limit exceeded (2GB on Render.com)
- **Solution**: Reduce API response size - use pagination (50 items max)
- **Check**: `/api/roadworks/unified` should use `limit=50` not `limit=500`

### **CORS Errors**  
- **Development**: Run backend locally (`npm run dev` in backend folder)
- **Production**: Backend already configured for gobarry.co.uk
- **Never**: Try to "fix" CORS by changing backend config

### **Roadworks Not Loading**
1. Check if backend is running (locally or on Render)
2. Verify pagination limit is 50 (not 500)
3. Check browser console for 503 errors
4. If using cached data, note the timestamp in error message

### **Memory Issues**
- Backend limited to 2GB RAM on Render.com
- All endpoints must be memory-optimized
- Use streaming/pagination for large datasets
- Monitor with `/api/memory` endpoint
