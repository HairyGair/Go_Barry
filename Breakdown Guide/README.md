# Go North East - Breakdown Guide App

## Project Overview
A digital wizard application for Go North East supervisors to diagnose bus engineering issues systematically, ensuring safety compliance and consistent decision-making.

## Project Structure
```
Breakdown Guide/
├── src/                    # Source files
│   ├── index.html         # Main application file
│   ├── styles.css         # Styling
│   ├── app.js            # Main application logic
│   └── data/             # Issue definitions
├── assets/                # Static assets
│   ├── images/           # Images and logos
│   └── icons/            # Icons for issues
├── docs/                  # Documentation
├── tests/                 # Test scenarios
└── data/                  # Data files and configurations
```

## Key Principles
- Safety is non-negotiable - critical issues must be immediately apparent
- Decisions must align with DVSA standards
- Balance safety with service continuity
- Every action must be logged for accountability
