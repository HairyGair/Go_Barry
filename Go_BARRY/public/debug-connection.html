🔍 Backend Connection Debugger

Let's figure out what's happening with your backend connection...

Manual Check:

Run this command to see what port your backend is using:

lsof -i :8080

Or check if it's on port 3001:

lsof -i :3001

Direct API Test:

Try these URLs in a new browser tab:

  • http://localhost:8080/api/health
  • http://localhost:3001/api/health
  • http://localhost:8080/api/admin-breakdowns
  • http://localhost:3001/api/admin-breakdowns
