🔗 Critical Dependencies

  • All Wizards depend on → React, Icons, BreakdownInfoStep, LocationInput, SupervisorBreakdownLogger
  • App.js depends on → All components (must load last)
  • Fleet Modals depend on → FleetDatabase, React
  • Location Components depend on → TomTom API, LocationCapture service
  • Analytics depends on → SupervisorBreakdownLogger, Backend API
  • Mobile Components depend on → Base wizards, MobileIntegration
  • PWA Features depend on → Service Worker, PWAManager
