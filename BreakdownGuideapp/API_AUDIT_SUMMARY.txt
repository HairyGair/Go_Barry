================================================================================
SECURITY CONSIDERATIONS
================================================================================

Authentication:
- JWT tokens issued with 24-hour expiration
- Passwords hashed with bcrypt (10 rounds)
- Email validation required for signup
- Badge number validation (format: AB123)

Authorization:
- Admin-only endpoints: 9 total
- Role-based access: Admin, Supervisor, System
- Missing: Field-level authorization
- Missing: Resource ownership validation

Data Protection:
- No documented encryption at rest
- HTTPS recommended but not enforced in code
- No rate limiting visible in production
- Activity audit trails logged but retention unclear

Vulnerabilities Identified:
1. Most endpoints accept unauthenticated requests
2. No input sanitization documented
3. Password resets possible without email verification
4. No CSRF protection visible
5. No request signing for critical operations
