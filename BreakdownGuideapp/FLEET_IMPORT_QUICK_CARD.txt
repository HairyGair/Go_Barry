COLUMN MAPPING (This is ALL you need to do)

  Your CSV Column          →    Database Column
  ──────────────────────────────────────────────
  FleetNo                  →    fleet_no
  RegNumber                →    registration
  OperatingDepotCode       →    depot
  VehicleType Equinox      →    vehicle_type

════════════════════════════════════════════════════════════════════════════

DBEAVER IMPORT STEPS

  1. Right-click fleet_vehicles table
  2. Import Data → Import from CSV File
  3. Select your CSV file
  4. Settings: UTF-8, Comma delimiter, First line as header
  5. Map the 4 columns above (UNCHECK EVERYTHING ELSE)
  6. Merge strategy: Update existing + Insert new, key = fleet_no
  7. Click Finish
  8. Done!

IF IMPORT FAILS

  Problem: "Column not found"
  → You tried to map a column that doesn't exist
  → Solution: Only map the 4 columns listed above

  Problem: "Fleet_no doesn't have a default value"
  → Some FleetNo cells are empty
  → Solution: Ensure all FleetNo cells have values in CSV

  Problem: "Duplicate entry"
  → Duplicate FleetNo values
  → Solution: This is OK, merge strategy handles it
