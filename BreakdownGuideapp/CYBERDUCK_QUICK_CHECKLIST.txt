TROUBLESHOOTING
================================================================================

Problem: "Cannot find module"
→ Check if all files uploaded correctly
→ Re-upload missing files
→ Run npm ci --production again

Problem: 500 errors on login
→ Check cookie-parser installed: npm list cookie-parser
→ Check server.js has cookie-parser middleware
→ Restart: pm2 restart breakdown-backend

Problem: Validation not working
→ Check validation/schemas.js exists at ~/api/validation/schemas.js
→ Check authMiddleware.js imports from validation
→ Restart: pm2 restart breakdown-backend

Problem: Files already exist error in CyberDuck
→ Click "Replace" to overwrite with new version
→ This is expected for modified files

Problem: New folder validation/ not appearing
→ CyberDuck may need refresh (Cmd+R or F5)
→ Try uploading schemas.js to existing route, it will auto-create folder
