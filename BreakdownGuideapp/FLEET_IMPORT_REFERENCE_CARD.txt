DBEAVER IMPORT STEPS
================================================================================
1. Right-click fleet_vehicles table
2. Import Data → Import from CSV File
3. Select your CSV file → Next
4. Encoding: UTF-8, Delimiter: Comma, First line as header: ✓ → Next
5. Map columns using table above → Next
6. ✓ Update existing records
   ✓ Insert new records
   Matching key: fleet_number
7. Click Finish
8. Check Log tab for success message

MERGE STRATEGY BEHAVIOR
================================================================================
✓ Updates vehicles that exist (by fleet_number)
✓ Adds vehicles that are new in CSV
✓ Preserves timestamps and unmapped fields
✓ No data loss - safest option

VALIDATION QUERIES (Run After Import)
================================================================================
-- Total count
SELECT COUNT(*) as total_vehicles FROM fleet_vehicles;

-- By depot
SELECT depot, COUNT(*) FROM fleet_vehicles
GROUP BY depot ORDER BY depot;

-- Check for problems
SELECT COUNT(*) FROM fleet_vehicles
WHERE fleet_number IS NULL;

-- Check for duplicates
SELECT fleet_number, COUNT(*) FROM fleet_vehicles
GROUP BY fleet_number HAVING COUNT(*) > 1;

TROUBLESHOOTING
================================================================================
Problem              Cause                 Solution
────────────────────────────────────────────────────────────────────────────
Duplicate entry      Fleet # exists        Choose "Update existing records"
Column not found     Wrong mapping         Verify CSV headers match mapping
Wrong data imported  Bad column mapping    Review mapping table above
Import is slow       Large file            Split CSV, import in chunks
Can't undo           No backup             Delete by timestamp:
                                           WHERE created_at > '2025-11-10'

ROLLBACK (If Something Goes Wrong)
================================================================================
-- Delete recently imported vehicles
DELETE FROM fleet_vehicles
WHERE created_at > DATE_SUB(NOW(), INTERVAL 1 HOUR);

-- Or specific depot
DELETE FROM fleet_vehicles
WHERE depot = 'BENH' AND created_at > '2025-11-10 12:00:00';
