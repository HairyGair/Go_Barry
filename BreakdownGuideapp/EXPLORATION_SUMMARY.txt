KEY FEATURES
================================================================================

1. AUTHENTICATION & AUTHORIZATION
   - Badge-based supervisor login (13 active users)
   - JWT token-based stateless auth
   - Role-based access control (Admin, Supervisor, Manager)
   - Rate limiting (5 login attempts per 15 mins)
   - 24-hour token expiration

2. BREAKDOWN MANAGEMENT
   - Auto-generated IDs (BRK-YYYYMMDD-NNN format)
   - Full CRUD operations
   - Location tracking with GPS + What3Words
   - Status lifecycle tracking
   - Severity classifications (STOP, AMBER, CONTINUE)

3. DIAGNOSTIC WIZARDS (42 types)
   - Steering & control systems
   - Brake systems
   - Engine & cooling
   - Electrical systems
   - HVAC (heating, ventilation, air conditioning)
   - Transmission/gearbox
   - Suspension & wheels
   - Safety systems (wheelchair ramps, etc.)
   - Conditional logic with branching questions
   - Safety severity determination

4. DASHBOARDS
   - Management Dashboard (executive KPIs)
   - Control Room Display (large format real-time)
   - SDC Operations Dashboard (breakdown tracking)
   - Engineering Dashboard (assignments & tracking)
   - Analytics & reporting views

5. REAL-TIME FEATURES
   - WebSocket event streaming
   - Activity feed with live updates
   - Engineer dispatch notifications
   - Breakdown status changes
   - Live breakdown counter

6. ANALYTICS & REPORTING
   - KPI tracking (by depot, engineer, vehicle)
   - Trend analysis (hourly, daily, weekly)
   - Performance metrics
   - Repeat breakdown detection
   - Cost analysis
   - Fleet health scoring

7. ENGINEERING MANAGEMENT
   - Engineer profile management
   - Skill-based matching
   - Location-based auto-assignment
   - ETA tracking
   - Performance analytics

8. ACTIVITY AUDIT TRAIL
   - Comprehensive event logging
   - Filterable activity stream
   - Full-text search
   - Pagination support
   - Storage in MySQL + JSON fallback

QUICK START
================================================================================

For Developers:

1. Setup Environment
   - Clone repository
   - Copy .env.example to .env (both frontend and backend)
   - Install dependencies: npm install (in both directories)

2. Start Development
   - Frontend: cd frontend && npm run dev
   - Backend: cd backend && npm run dev

3. Database
   - MySQL connection configured in backend/.env
   - Migrations in backend/migrations/
   - Apply as needed

4. Testing
   - Login with supervisor badge (e.g., AG003)
   - Create breakdown
   - Run wizard assessment
   - Check real-time updates

For Deployment:

1. Build
   - Frontend: npm run build:cpanel
   - Backend: No build needed (Node.js)

2. Deploy
   - Frontend: Push dist/ to cPanel
   - Backend: Deploy via Render.com or cPanel App Manager

3. Verify
   - Check frontend at https://breakdowns.gobarry.co.uk
   - Check backend health endpoint
   - Test supervisor login
