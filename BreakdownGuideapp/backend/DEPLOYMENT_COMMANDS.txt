=====================================================

2. Navigate to /home/gobarryco/ (home directory)

------------------------------------

Then copy-paste these commands:

mv ~/gobarry-backend-deploy ~/gobarry-backend-backup-$(date +%Y%m%d-%H%M%S)

unzip -q ~/gobarry-backend.zip -d ~/gobarry-backend-deploy

CRITICAL FIX INCLUDED
=====================

The gobarry-backend.zip includes the fix for route ordering in supervisors.js:

BEFORE (BROKEN):
  Line 428: router.get('/:id', ...)        ← Catches everything first!
  Line 93:  router.get('/:id/stats', ...) ← Never reached

AFTER (FIXED):
  Line 93:  router.get('/:id/stats', ...) ← Specific route first
  Line 428: router.get('/:id', ...)        ← Generic route last

This ensures /api/supervisors/AG003/stats correctly returns statistics
instead of treating "stats" as an ID parameter.
