StreetManager Integration Setup

Option 1: Webhook Registration (Recommended)

  1. Visit Find and use roadworks data
  2. Register for an account with your organization details
  3. Configure webhook URL:
    https://go-barry.onrender.com/api/streetmanager/webhook
  4. Select "North East England" as your area of interest
  5. Wait for AWS SNS subscription confirmation

Option 2: API Polling

  1. Register for API access at the same link above
  2. Get your API key from the StreetManager portal
  3. Add to your environment variables:
    STREET_MANAGER_API_KEY=your_api_key_here
  4. Set up a cron job to poll every 30 minutes:
    POST https://go-barry.onrender.com/api/streetmanager/poll

Webhook Endpoint Details

Endpoint: https://go-barry.onrender.com/api/streetmanager/webhook Method: POST Headers: Expects AWS SNS headers (x-amz-sns-message-type) Authentication: None required (validates SNS signatures)

Available API Endpoints

  • GET /api/streetmanager/notifications - List all notifications
  • GET /api/streetmanager/active-today - Today's active roadworks
  • GET /api/streetmanager/active-roadworks - All active roadworks
  • GET /api/streetmanager/summary - Summary statistics
  • GET /api/streetmanager/diagnostics - System diagnostics
  • POST /api/streetmanager/poll - Manual API poll (requires API key)
