Vehicle Locations (SIRI-VM)\n**Endpoint**: `https://data.bus-data.dft.gov.uk/api/v1/datafeed`\n**Format**: XML/JSON\n**Update Frequency**: Real-time (30-second refresh)\n**Data Points**:\n- Vehicle reference\n- Route/Line reference\n- GPS coordinates\n- Bearing/Direction\n- Delay information\n- Timestamp\n\n### 2. Timetables (TransXChange)\n**Endpoint**: `https://data.bus-data.dft.gov.uk/api/v1/dataset`\n**Format**: XML (TransXChange schema)\n**Update Frequency**: Daily/Weekly\n**Data Points**:\n- Service patterns\n- Stop sequences\n- Journey times\n- Operating periods\n- Route descriptions\n\n### 3. Fares (NeTEx)\n**Endpoint**: `https://data.bus-data.dft.gov.uk/api/v1/fares`\n**Format**: XML (NeTEx schema)\n**Update Frequency**: Weekly/Monthly\n**Data Points**:\n- Fare products\n- Tariff zones\n- Price structures\n- Validity periods\n\n## Performance Considerations\n\n### Optimization Strategies\n\n1. **Viewport-based Loading**: Only process data within current view\n2. **Incremental Updates**: Delta processing for large datasets\n3. **Memory Management**: Stream processing and automatic cleanup\n4. **Caching Layers**: Multi-level caching with appropriate TTLs\n5. **Batch Processing**: Group API calls to minimize requests\n\n### Memory Limits\n\n**2GB RAM Constraint (Render.com):**\n- Stream-based XML parsing\n- Pagination for large datasets\n- Automatic memory monitoring\n- Cache size limits and rotation\n- Garbage collection triggers\n\n## Monitoring & Analytics\n\n### Health Metrics\n\n```javascript\ngetHealthStatus() {\n  const successRate = this.metrics.totalRequests > 0 \n    ? this.metrics.successfulRequests / this.metrics.totalRequests \n    : 1;\n  \n  if (successRate > 0.9) return 'healthy';\n  if (successRate > 0.7) return 'degraded';\n  return 'unhealthy';\n}\n```\n\n### Performance Tracking\n\n- **API Response Times**: Track average and peak response times\n- **Cache Hit Rates**: Monitor cache effectiveness\n- **Error Rates**: Track failure patterns and causes\n- **Data Freshness**: Monitor data age and update frequencies\n\n## Future Enhancements\n\n### Planned Features\n\n1. **Real-time Comparison Engine**\n   -
