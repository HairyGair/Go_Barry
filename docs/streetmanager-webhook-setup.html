🚧 Go BARRY - Street Manager Webhook Setup

Configure real-time roadwork updates from manage-roadworks.service.gov.uk

✅ Webhook Endpoint Ready:
https://go-barry.onrender.com/api/streetmanager/webhook

📋 Setup Instructions

Create Account
Visit manage-roadworks.service.gov.uk/open-data-onboarding and create an account for open data access.
Register Webhook Endpoint
In the registration form, provide the following endpoint URL:
https://go-barry.onrender.com/api/streetmanager/webhook
Wait for Confirmation
Street Manager will send a subscription confirmation request. Our endpoint will automatically confirm it and log the confirmation URL.
Start Receiving Events
Once confirmed, you'll receive real-time notifications for:
  • New permits created
  • Permit status changes
  • Work start/stop notifications
  • Activity updates

🔧 Technical Details

The Street Manager service uses AWS SNS (Simple Notification Service) to push events to registered endpoints.

⚠️ Important: The endpoint must be publicly accessible and able to handle AWS SNS subscription confirmations.

📡 Available Endpoints

POST /api/streetmanager/webhook
Receives SNS notifications from Street Manager
GET /api/streetmanager/webhook/status
Check webhook configuration and subscription status
POST /api/streetmanager/webhook/test
Test endpoint to simulate Street Manager events

📊 Event Types

The webhook processes the following event types:

  • PERMIT_CREATED - New roadwork permit
  • PERMIT_GRANTED - Permit approved
  • PERMIT_REFUSED - Permit rejected
  • WORK_START - Work has begun
  • WORK_STOP - Work paused/stopped
  • WORK_COMPLETE - Work finished
  • ACTIVITY_CREATED - New roadwork activity
  • ACTIVITY_UPDATED - Activity details changed

🗺️ Coverage Area

Events are automatically filtered for the North East England region:

  • Newcastle
  • Gateshead
  • Sunderland
  • Durham
  • North Tyneside
  • Northumberland

Coordinates outside this area are automatically excluded.
